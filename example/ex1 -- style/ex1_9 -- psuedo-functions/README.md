# NOTICE
## About `:is()` and `:where()`
> [!NOTE]
> `:is()` and `:where()` can NOT be used with either `:Before` or `:After` (of course, or both).

> [!NOTE]
> `:is()` and `:where()` has same behavior, but `:is()` has higher priority.

> [!NOTE]
> `:is()` has higher priority than `:where()`.

## About `:has()`
> [!WARNING]
> It is only available since 2023.

For more details, see [`:has()`](https://developer.mozilla.org/en-US/docs/Web/CSS/:has)
