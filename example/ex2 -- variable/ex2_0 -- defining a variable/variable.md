# variable in CSS
## history
Since 2012, `W3C` rules variables in original `CSS`. 

However, many web browsers does NOT support it in original CSS (NOT including extension of `CSS`, such as `SCSS`).

Fortunately, I remember that many web browsers suport it in about 2018.

![compatibility table](image.png)

For more details, see the compatibility table of [`var()`](https://developer.mozilla.org/en-US/docs/Web/CSS/var)
