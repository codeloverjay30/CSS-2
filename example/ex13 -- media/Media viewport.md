# Media viewport

+ About height

| value | desccription |
| ----- | ------------ |
| `height` | `height of the viewport (including scrollbar)`|
| `max-height` | `max height of the viewport (including scrollbar)`|
| `min-height` | `min height of the viewport (including scrollbar)`|

+ About width

| value | desccription |
| ----- | ------------ |
| `width` | `width of the viewport (including scrollbar)`|
| `max-width` | `max width of the viewport (including scrollbar)`|
| `min-width` | `min width of the viewport (including scrollbar)`|
