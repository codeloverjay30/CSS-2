# CSS preference color scheme
You can check the current preference color scheme by accessing `prefers-color-scheme`

| value | desccription |
| ----- | ------------ |
| `no-preference` | `when has no preference color scheme` | 
| `light` | `when has preference color scheme -- light scheme` | 
| `dark` | `when has preference color scheme -- dark scheme`|
