# CSS Media Types
You can check the current media types.

| value | desccription |
| ----- | ------------ |
| `all` | `all media type devices` |
| `print` | `print preview mode` |
| `screen` |`computer screens, tablets, smart-phones etc.` |
| `speech` | `speech mode` (for disables) |
